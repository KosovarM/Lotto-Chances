# Lottery statistics disclaimer

CodingProjekt1's Lotto 6aus49 tool is for **education and historical analysis**.

- Each official draw is an independent random process (under fair lottery rules).
- Frequency charts describe **what happened**, not **what will happen**.
- No feature in this project should suggest improved odds or "lucky" combinations based on history.

If you add UI or CLI output, include a short reminder of this fact.
